# smart-temperature-alert-system
A embedded systems project that monitors temperature using a TMP36 sensor and provides visual and audible alerts based on the measured temperature.
Features:

 - Real-time temperature monitoring
 - Normal/Warm/High temperature classification
 - Green LED for normal conditions
 - Red LED for elevated temperature
 - Buzzer warning for high temperature
 - Serial Monitor output

Technologies:

 - Arduino Uno
 - TMP36
 - Embedded C/C++
 - Tinkercad Circuits

Future improvements:

 - Add an LCD display
 - Add Wi-Fi monitoring using ESP8266/ESP32
 - Send alerts to a mobile phone
 - Store temperature data
 - Create a web dashboard
